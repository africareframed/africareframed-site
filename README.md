# africareframed.com

The public site of Africa Reframed. The archive lives on PhotoDeck at archive.africareframed.com; this site is the window onto it.

- Pages are generated from one template: `python3 src/build.py` writes `index.html`, `themes/`, `partners/`, `about/`, `request-access/` and `assets/site.css` into the repository root.
- The header exists once, in `src/build.py`. The bridge (the `?in=1` marker that switches the header to the archive tools) lives in the inline script there.
- Brief and build plan: "Website – Brief and build plan" (Google Doc, 05 Website on the Africa Reframed Drive).
