How to read the wireframe

  • Grey box with a crossAn image still to choose, at the size and proportion it will have.
  • Grey barsText still to write.
  • Yellow noteWhat goes there, and where it comes from.
  • Clean viewIn the yellow strip: hides the notes and labels, so a page can be shown as a layout.
  • GridIn the yellow strip, or the key G, or ?grid in the address: draws the columns (blue) and margins (red) of the current width, with the values in a readout.
  • Module labelsEvery section carries the number and variant of the module it is built from (Website – modules); hidden in clean view. All modules with their variants: /dev/modules.
  • Draft copyText with a dotted underline is draft copy written from the masters, to be approved by Thomas; the mark hides in clean view.
